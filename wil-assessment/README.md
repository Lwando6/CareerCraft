# CareerCraft WIL Agile Portfolio

This folder contains the evidence portfolio for **Assessment 2: GitHub Portfolio (WIL Projects and Industry Placements)**.

## Entrepreneurial WIL Project

**CareerCraft** is a South Africa-first digital career platform that helps students and graduates maintain one reusable career profile and turn it into recruiter-ready CVs, portfolios, LinkedIn content and application documents.
